# 🌟 “Aku Patuh pada Aturan: Mengenal Aturan di Rumah dan di Sekolah”
### Media Pembelajaran Interaktif untuk Siswa Usia Dini & Sekolah Dasar Kelas Rendah

---

## 📖 Tentang Proyek

Website pembelajaran interaktif **“Aku Patuh pada Aturan”** dirancang secara khusus untuk membantu anak-anak usia dini dan siswa sekolah dasar kelas rendah (Kelas 1–2 SD) memahami, mencintai, dan mematuhi aturan sehari-hari di rumah serta di sekolah.

Pembelajaran tidak dilakukan secara kaku atau teoritis, melainkan melalui petualangan visual kartun 2D bersama **tiga karakter sahabat**:
1. **Panca 🧢**: Karakter ceria, aktif, dan suka mengajak anak melakukan kegiatan sehari-hari.
2. **Sila 🌸**: Karakter ramah dan bijak yang menjelaskan pentingnya aturan, rasa syukur, dan berbuat baik.
3. **Bina ⭐**: Karakter pintar dan penuh tantangan yang memandu permainan mencocokkan kartu dan kuis interaktif.

---

## ✨ Fitur-Fitur Utama

1. **Beranda Interaktif**:
   - Judul & Subjudul ramah anak dengan gaya visual kartun 2D modern.
   - Panca, Sila, dan Bina menyapa dengan animasi melambaikan tangan (*hand wave*), berkedip (*blinking eyes*), dan melompat kecil (*gentle bounce*).
   - Tombol **Mulai Belajar**, **Dengarkan Sapaan** (narasi suara bahasa Indonesia ceria), dan **Petunjuk Belajar** (modal panduan interaktif).

2. **Materi 1 — Aturan dalam Keluargaku**:
   - Pembagian aturan rumah berdasarkan waktu:
     - 🌅 **Pagi Hari**: Bangun tepat waktu, merapikan selimut/bantal, mandi, dan sarapan bersama keluarga.
     - ☀️ **Siang Hari**: Pulang tepat waktu, cuci tangan pakai sabun, dan makan dengan tertib.
     - 🌇 **Sore Hari**: Merapikan mainan ke kotak penyimpanan dan membantu orang tua menyapu.
     - 🌙 **Malam Hari**: Belajar, menyiapkan tas dan buku pelajaran, serta tidur tepat waktu.
   - Dilengkapi tombol *Dengarkan*, *Ulangi*, dan *Selanjutnya*.

3. **Materi 2 — Aku Mematuhi Aturan di Rumah**:
   - Menampilkan 4 kebiasaan baik:
     - 🙏 Berdoa sebelum & sesudah makan.
     - 🧼 Mencuci tangan pakai sabun di air mengalir.
     - 🧸 Mengembalikan mainan & barang pada tempatnya.
     - 🛏️ Menjaga kebersihan & kerapian kamar tidur.
   - **Fitur Interaktif Sebelum vs Sesudah**: Tombol perbandingan langsung untuk melihat transformasi visual antara perilaku yang belum tertib versus sudah tertib.

4. **Materi 3 — Aku Peduli dengan Tempat Tinggalku**:
   - Menjaga keasrian tempat tinggal:
     - 🗑️ Membuang sampah pada tempatnya.
     - 🍂 Menyapu halaman rumah dari daun kering.
     - 🌸 Merawat & menyiram tanaman bunga.
   - **Mengenal Alat Kebersihan**: Sapu, Pengki, dan Kemoceng (dapat diklik untuk melihat fungsi, animasi penggunaan, dan audio suara).
   - **Mini-Game "Pilih Alat yang Tepat"**: Tantangan interaktif memilih alat yang tepat untuk tugas kebersihan tertentu.

5. **Materi 4 — Aku Patuh Aturan di Sekolah**:
   - Suasana sekolah yang ceria (gerbang, tiang bendera, ruang kelas, papan tulis, dan tempat sampah pilah):
     - 🚶‍♂️ Berbaris dengan tertib & lurus sebelum masuk kelas/upacara.
     - 👩‍🏫 Mendengarkan bapak/ibu guru dengan tertib dan mengangkat tangan jika ingin bertanya.
     - 🤝 Melaksanakan tugas piket kelas secara gotong royong.
     - 🏫 Menjaga kebersihan lingkungan sekolah dengan membuang sampah pada tempatnya.

6. **Materi 5 — Ayo Bermain! (Permainan Mencocokkan)**:
   - 5 pasangan aturan wajib:
     1. Merapikan tempat tidur ➜ Pagi hari.
     2. Membuang sampah pada tempatnya ➜ Lingkungan rumah.
     3. Mendengarkan guru menjelaskan ➜ Di sekolah.
     4. Menyapu halaman rumah ➜ Kegiatan menjaga kebersihan rumah.
     5. Berdoa sebelum makan ➜ Kebiasaan saat makan.
   - Mekanisme klik untuk mencocokkan (*click-to-pair*), ramah perangkat layar sentuh (*touchscreen/tablet*).
   - Efek suara kemenangan, animasi pencocokan, skor progres, dan hujan konfeti saat selesai.

7. **Materi 6 — Kuis Interaktif (10 Soal Berbobot)**:
   - 10 pertanyaan pilihan ganda mencakup seluruh materi.
   - Soal dan pilihan jawaban diacak (*shuffled*) setiap kali kuis dimulai.
   - Tombol audio suara **"Bacakan Soal"** untuk anak yang sedang belajar membaca.
   - Umpan balik langsung dari Panca, Sila, dan Bina.
   - Perhitungan skor otomatis tanpa mempermalukan anak, dilengkapi tombol **Ulangi Kuis** dan **Kembali ke Materi**.

8. **Halaman Penutup & Sertifikat Kepatuhan**:
   - Panca, Sila, dan Bina melambaikan tangan memberikan ucapan selamat.
   - Pesan motivasi penutup dengan pembacaan audio.
   - **Sertifikat Bintang Kepatuhan**: Fitur khusus di mana anak dapat mengetikkan namanya sendiri dan mencetak piagam penghargaan (*printable certificate*).

9. **Sistem Audio Lengkap**:
   - Narasi bahasa Indonesia menggunakan **Web Speech API** (`id-ID`) yang dioptimalkan untuk suara anak yang ramah.
   - Efek suara (*SFX*) disintesis langsung menggunakan **Web Audio API** (tanpa ketergantungan file eksternal yang rawan rusak/hilang).
   - Kontrol suara: Tombol On/Off Narasi Suara dan On/Off Efek Suara pada navbar.

## 🛠️ Teknologi yang Digunakan

- **React 18**: Komponen modular, state management reaktif.
- **Vite 5**: Build tool modern berkecepatan tinggi.
- **Tailwind CSS 3**: Desain antarmuka responsif dan ramah anak.
- **Lucide React**: Ikonografi bersih dan jelas.
- **Canvas-Confetti**: Efek perayaan partikel visual ceria.
- **Web Speech API & Web Audio API**: Pengelolaan narasi suara & efek audio offline.

## 🚀 Panduan Instalasi dan Menjalankan

### Persyaratan Sistem:
- Komputer / Laptop dengan **Node.js** versi 18 ke atas.
- Browser modern (Google Chrome, Microsoft Edge, Mozilla Firefox, atau Safari).

### Langkah-langkah:
1. Buka terminal pada folder proyek:
   ```bash
   cd "c:\Users\iniha\OneDrive\Documents\AI\Website Teknologi"
   ```

2. Pasang dependensi:
   ```bash
   npm install
   ```

3. Jalankan server pengembangan lokal:
   ```bash
   npm run dev
   ```

4. Buka tautan lokal yang ditampilkan (biasanya `http://localhost:3000` atau `http://localhost:5173`) di browser Anda.

5. Untuk membuat file rilis produksi:
   ```bash
   npm run build
   ```
   File hasil build siap didistribusikan di dalam folder `dist/`.
